# Legenda morfológica OSHB (WLC)

Versão: 1.0.0 · Fonte: Open Scriptures Hebrew Bible morphology codes.

Formato: prefixo de língua `H` (hebraico) ou `A` (aramaico); morfemas separados
por `/` na mesma ordem dos segmentos do lemma (ex.: `HR/Ncfsa` = preposição +
substantivo comum feminino singular absoluto).

## Classes

| Código | Classe |
|---|---|
| A | Adjetivo (Aa cardinal/ordinal variantes: Ac cardinal, Ao ordinal, Ag gentílico) |
| C | Conjunção (waw etc.) |
| D | Advérbio |
| N | Substantivo — `Nc` comum, `Np` próprio |
| P | Pronome — `Pp` pessoal, `Pd` demonstrativo, `Pi` interrogativo, `Pr` relativo |
| R | Preposição — `Rd` preposição + artigo fundido |
| S | Sufixo — `Sp` pronominal (com pessoa/gênero/número), `Sd` he direcional, `Sh` paragógico |
| T | Partícula — `Td` artigo, `To` marcador de objeto direto (אֵת), `Tr` relativo, `Ti` interrogativa, `Tj` interjeição, `Te` exortação, `Ta` afirmação, `Tn` negação |
| V | Verbo |

## Verbo: `V` + tronco + conjugação + pessoa/gênero/número (+ estado p/ particípios)

Troncos: `q` qal, `N` nifal, `p` piel, `P` pual, `h` hifil, `H` hofal, `t` hitpael
(mais raros: `o` polel, `O` polal, `r` hitpolel, etc.)

Conjugações: `p` perfeito (qatal), `q` perfeito sequencial (weqatal), `i` imperfeito
(yiqtol), `w` imperfeito sequencial (**wayyiqtol**), `h` coortativo, `j` jussivo,
`v` imperativo, `r` particípio ativo, `s` particípio passivo, `a` infinitivo
absoluto, `c` infinitivo construto.

Pessoa `1|2|3`, gênero `m|f|b` (comum), número `s|p|d` (dual).

Ex.: `HVqw3ms` = hebraico, verbo qal wayyiqtol 3ª masculina singular ("e ele disse").

## Substantivo/adjetivo: gênero `m|f|b`, número `s|p|d`, estado `a` absoluto, `c` construto, `d` determinado

Ex.: `HNcfsa` = substantivo comum feminino singular absoluto.

## Lemma

Números de Strong estendidos: `b/7225` = prefixo bet + H7225 (רֵאשִׁית);
sufixo `a`/`b` distingue homógrafos (ex.: `1254 a` = ברא "criar").
